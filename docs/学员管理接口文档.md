# 学员管理

## 通用说明

### 统一响应格式

```json
{
  "state": 20000,       // 业务状态码
  "message": null,      // 错误时携带提示信息
  "data": { ... }       // 成功时携带数据
}
```

| state | 含义 |
|-------|------|
| 20000 | 成功 |
| 40000 | 请求参数错误 |
| 40100 | 未登录或 token 过期 |
| 40300 | 权限不足 |
| 40400 | 资源不存在 |
| 40900 | 数据冲突（如用户名已存在） |

### 认证方式

所有接口（除登录和注册外）需要在请求头中携带 Token：

```
Authorization: Bearer <token>
```

### 角色说明

| 值 | 角色 |
|----|------|
| 1 | 学员 |
| 2 | 教练 |
| 3 | 管理员 |

### 分页接口通用返回

分页接口返回 `Page<T>` 对象：

```json
{
  "state": 20000,
  "data": {
    "records": [...],   // 当前页数据
    "total": 56,        // 总记录数
    "pages": 6,         // 总页数
    "current": 1,       // 当前页码
    "size": 10          // 每页条数
  }
}
```

基础路径：`/students`

> 仅管理员可调用。所有接口自动限定 role=1（学员角色）。

### 2.1 分页查询学员

```
GET /students?page=1&size=10&status=1&username=student&realName=王
```

| 参数 | 说明 | 必填 |
|------|------|------|
| page | 页码，默认 1 | 否 |
| size | 每页条数，默认 10 | 否 |
| status | 审核状态筛选：0-待审核，1-已通过，2-未通过 | 否 |
| username | 用户名模糊搜索（LIKE %keyword%） | 否 |
| realName | 姓名模糊搜索（LIKE %keyword%） | 否 |

> 以上参数可任意组合使用，例如：
> - `?status=0` 查待审核的学员
> - `?realName=赵` 查姓赵的学员
> - `?username=student&status=1` 查已通过且用户名含 student

**响应：**
```json
{
  "state": 20000,
  "data": {
    "records": [
      {
        "userId": 4,
        "role": 1,
        "username": "student1",
        "realName": "王小明",
        "idCard": "500101200001011234",
        "phone": "15912340001",
        "address": "重庆市南岸区学府大道",
        "licenseType": "C1",
        "avatar": null,
        "status": 1,
        "auditReason": null,
        "createTime": "2026-05-22T12:00:00",
        "updateTime": "2026-05-22T12:00:00"
      }
    ],
    "total": 5,
    "pages": 1,
    "current": 1,
    "size": 10
  }
}
```

### 2.2 查询学员详情

```
GET /students/{studentId}
```

### 2.3 新增学员

```
POST /students
Content-Type: application/json

{
  "username": "student3",
  "password": "admin123",
  "realName": "张三",
  "idCard": "500101200205036789",
  "phone": "15912340003",
  "address": "重庆市南岸区",
  "licenseType": "C1"
}
```

> - 角色自动设为学员（role=1）
> - 密码会自动 BCrypt 加密后入库
> - `status` 默认为待审核

### 2.4 修改学员信息

```
PUT /students/{studentId}
Content-Type: application/json

{
  "realName": "张三改",
  "phone": "15912340099",
  "address": "重庆市江北区"
}
```

> `password` 传空字符串或 null 不会覆盖原密码

### 2.5 删除学员（逻辑删除）

```
DELETE /students/{studentId}
```

> 数据软删除（`is_deleted=1`），不会真的从数据库移除

基础路径：`/registrations`

### 5.1 查询待审核学员

```
GET /registrations/pending
```

> 仅管理员可调用，返回所有 `status=0` 的学员

### 5.2 审核学员报名

```
PUT /registrations/{userId}/audit?pass=true
```

| 参数 | 说明 | 必填 |
|------|------|------|
| pass | true=通过，false=不通过 | 是 |
| reason | 不通过原因（pass=false 时必填） | 否 |

> - 仅管理员可调用
> - 审核通过时：`user.status = 1`，自动生成报名表 PDF + 准考证 PDF
> - 审核不通过时：填写原因，`user.status = 2`

### 5.3 查询学员的报名文件

```
GET /registrations/{userId}/files
```

> 返回该学员的所有报名表和准考证 PDF 文件记录，可用于前端展示下载链接

```
GET /students/{studentId}/progress
```

    "licenseType": "C1",
    "progressPercent": 25,
    "subjects": [
      {
        "subject": 1,
        "status": "passed",
        "score": 95,
        "description": "科目一 道路交通安全法律、法规和相关知识",
        "examItems": null,
        "requiredHours": 0,
        "trainedHours": 0,
        "remainingHours": 0
      },
      {
        "subject": 2,
        "status": "learning",
        "description": "科目二 场地驾驶技能",
        "examItems": ["倒车入库", "侧方停车", "坡道定点停车和起步", "直角转弯", "曲线行驶"],
        "requiredHours": 16,
        "trainedHours": 14,
        "remainingHours": 2
      },
      {
        "subject": 3,
        "status": "locked",
        "description": "科目三 道路驾驶技能",
        "examItems": ["上车准备", "起步", "直线行驶", ...],
        "requiredHours": 24,
        "trainedHours": 0,
        "remainingHours": 24
      },
      {
        "subject": 4,
        "status": "locked",

**status 含义：**

| 值 | 说明 | 前端显示 |
|----|------|---------|
| `locked` | 前一科未通过，此科锁定 | 灰色锁图标 |
| `learning` | 学习中，学时未达标 | 进度条（如 14/16） |
| `ready` | 学时已达标，可以报名考试 | 绿色"可报名"按钮 |
| `passed` | 考试已通过 | ✅ 绿色打勾 |

| `POST /register` | 注册 |

| `GET /users/me` | 查看个人信息/审核状态 |
| `PUT /users/{id}/password` | 修改密码 |

| 接口 | 用途 |
|------|------|
