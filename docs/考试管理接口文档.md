# 考试管理

## 通用说明

### 统一响应格式

```json
{
  "state": 20000,       // 业务状态码
  "message": null,      // 错误时携带提示信息
  "data": { ... }       // 成功时携带数据
}
```

| state | 含义 |
|-------|------|
| 20000 | 成功 |
| 40000 | 请求参数错误 |
| 40100 | 未登录或 token 过期 |
| 40300 | 权限不足 |
| 40400 | 资源不存在 |
| 40900 | 数据冲突（如用户名已存在） |

### 认证方式

所有接口（除登录和注册外）需要在请求头中携带 Token：

```
Authorization: Bearer <token>
```

### 角色说明

| 值 | 角色 |
|----|------|
| 1 | 学员 |
| 2 | 教练 |
| 3 | 管理员 |

### 分页接口通用返回

分页接口返回 `Page<T>` 对象：

```json
{
  "state": 20000,
  "data": {
    "records": [...],   // 当前页数据
    "total": 56,        // 总记录数
    "pages": 6,         // 总页数
    "current": 1,       // 当前页码
    "size": 10          // 每页条数
  }
}
```

基础路径：`/exam-sessions`

### 9.1 分页查询考试场次

```
GET /exam-sessions?page=1&size=10&subject=2&licenseType=C1
```

| 参数 | 说明 | 必填 |
|------|------|------|
| page | 页码，默认 1 | 否 |
| size | 每页条数，默认 10 | 否 |
| subject | 科目筛选（1-4） | 否 |
| licenseType | 车型筛选（C1/C2/B1） | 否 |

> 任意登录用户可调用，按考试日期升序排列

### 9.2 查询场次详情

```
GET /exam-sessions/{id}
```

### 9.3 发布考试场次

```
POST /exam-sessions
Content-Type: application/json

{
  "subject": 2,
  "examDate": "2026-06-15",
  "startTime": "09:00",
  "location": "重庆市南岸区考场",
  "totalQuota": 50,
  "remainingQuota": 50,
  "licenseType": "C1",
  "status": 1
}
```

> 仅管理员可调用。`totalQuota` = 总名额，`remainingQuota` = 剩余名额（发布时 = totalQuota）

### 9.4 修改考试场次

```
PUT /exam-sessions/{id}
Content-Type: application/json

{
  "examDate": "2026-06-16",
  "location": "重庆市江北区考场",
  "remainingQuota": 40,
  "status": 1
}
```

> 仅管理员可调用

### 9.5 删除考试场次

```
DELETE /exam-sessions/{id}
```

> 仅管理员可调用，逻辑删除

基础路径：`/exam-registrations`

### 10.1 学员报名考试

```
POST /exam-registrations?studentId=4&sessionId=1
```

| 参数 | 说明 | 必填 |
|------|------|------|
| studentId | 学员ID | 是 |
| sessionId | 考试场次ID | 是 |

> - 仅学员可调用
> - 自动校验：车型是否匹配、学时是否达标、名额是否充足

### 10.2 查询学员的考试报名记录（我的成绩）

```
GET /exam-registrations/student/{studentId}
```

> 任意登录用户可调用
> - 学员用于查看自己的考试成绩
> - 返回记录包含 `score`（成绩）、`passStatus`（1-合格/0-不合格）、`retakeCount`（补考次数）

**响应：**
```json
{
  "state": 20000,
  "data": [
    {
      "id": 1,
      "studentId": 4,
      "sessionId": 1,
      "subject": 1,
      "status": 3,
      "score": 95,
      "passStatus": 1,
      "retakeCount": 0,
      "applyTime": "2026-05-25T10:00:00"
    }
  ]
}
```

**status 含义：** 0-待审核, 1-已通过, 2-未通过, 3-已考试

### 10.3 分页查询所有报名记录

```
GET /exam-registrations?page=1&size=10
```

> 仅管理员可调用

### 10.4 审核考试报名

```
PUT /exam-registrations/{id}/audit?pass=true
```

| 参数 | 说明 | 必填 |
|------|------|------|
| pass | true=通过，false=不通过 | 是 |

> - 仅管理员可调用
> - 审核通过：扣减场次名额，生成带考试信息的准考证 PDF
> - 名额归零时自动标记场次为已满

### 10.5 录入成绩

```
PUT /exam-registrations/{id}/score?score=95
```

| 参数 | 说明 | 必填 |
|------|------|------|
| score | 0-100 的整数 | 是 |

> - 仅管理员可调用
> - ≥90 合格（`passStatus=1`），不合格自动 `retakeCount+1`

### 接口速查（按角色）

**学员可调用的 API：**
| 接口 | 用途 |
|------|------|
| `POST /register` | 注册 |
| `POST /appointments` | 约课 |
| `PUT /appointments/{id}/cancel` | 取消约课 |
| `POST /coach-applications` | 申请教练 |
| `POST /exam-registrations` | 报名考试 |
| `POST /files/upload` | 上传文件 |
| `GET /files/user/{userId}` | 查看我的文件 |
| `GET /exam-registrations/student/{studentId}` | 我的成绩 |
| `GET /students/{studentId}/progress` | 查看学时进度 |
| `GET /users/me` | 查看个人信息/审核状态 |
| `PUT /users/{id}/password` | 修改密码 |

**教练可调用的 API：**
| 接口 | 用途 |
|------|------|
| `GET /appointments?coachId={id}` | 查看我的课程安排 |

**管理员可调用的 API：**
| 接口 | 用途 |
|------|------|
| `GET/POST/PUT/DELETE /students/**` | 学员管理（增删改查） |
| `PUT /registrations/{userId}/audit` | 审核报名 |
| `PUT /coach-applications/{id}/audit` | 审核教练申请 |
| `POST /coach-assignments` | 分配教练 |
| `PUT /coach-assignments/{id}/unbind` | 解绑教练 |
| `PUT /exam-registrations/{id}/audit` | 审核考试报名 |
| `PUT /exam-registrations/{id}/score` | 录入成绩 |
| `POST/PUT/DELETE /exam-sessions/**` | 管理考试场次 |
| `GET /statistics/**` | 查看统计报表 |
| `POST/PUT/DELETE /fee-standards/**` | 费用标准管理 |
| `POST/PUT/DELETE /license-configs/**` | 车型配置管理 |
| `DELETE /files/{id}` | 删除文件 |
| `POST/PUT/DELETE /coaches/**` | 教练管理 |
